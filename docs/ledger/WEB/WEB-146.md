## Livré

`WEB-146` **Les bornes kilométriques sur la carte d'ensemble d'un voyage** (9 novembre 2026, contrat inchangé, pendant de `MOB-122`) — **revient sur** le « sans effet sur plusieurs tracés » de `WEB-145` : `RoutesMapView` pose avec `kmMarkers` les bornes de tous les tracés visibles, et c'est la page qui décide. `TripOverviewMap` l'active hors mode Météo ; chaque étape compte depuis son propre départ. `KmMarkersTracesLayer` (`MapMarkers.tsx`) mesure toutes les traces ensemble, pour que les bornes d'étapes voisines se cèdent la place. Couvert par `RoutesMapView.test.tsx` et `TripOverviewMap.test.tsx`. À ne pas défaire : pas de kilométrage cumulé sur le voyage ; toujours pas de bornes sur une sortie à plusieurs parcours.
