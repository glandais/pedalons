## Reste à faire

`WEB-198` **Recette du choix du calcul d'itinéraire dans le planificateur** —
le choix « Calcul d'itinéraire » (Standard / Routes de l'équipe, ou Pédalons sans équipe) du panneau des
profils (`RouterProfileSelector`, `API-217`) n'a été vu ni dans un navigateur ni dans l'app : les
tests unitaires passent, les deux cas e2e de `frontend/e2e/gpx-planner.e2e.ts` sont écrits et jamais
lancés. À voir, une fois le moteur `1.16.0` en service (`OPS-68`) : la largeur du choix dans le panneau
de 260 px (« Routes de l'équipe » peut passer sur deux lignes), la présentation tactile, le choix
gardé après rechargement, un tronçon réellement calculé par le moteur dans une équipe qui a sa
surcouche (il doit suivre ses routes), le repli sur Stadia au-delà de 100 km, et la même chose dans
l'app (bundle du planificateur, pont `GET /api/router/engines`). Lancer aussi la suite e2e.
