## Livré

`WEB-180` **« Dupliquer » sur la page d'un aperçu GPX** (13 novembre 2026, contrat `14.12.0` par `API-197`) — `GpxPreviewView` place « Dupliquer » (icône copie) dans la rangée d'actions pour tout compte connecté, créateur ou non ; un anonyme ne le voit pas. `DuplicateRouteModal` est généralisée par sa prop `target` (`'route'` par défaut, `'preview'` : clés `gpxTools.preview.duplicate.*`, schéma `CopyGpxPreviewBody`, 200 caractères) au lieu d'être copiée ; le champ s'appelle « Nom du parcours » comme dans l'éditeur d'un aperçu, prérempli « Copie de {nom} ». Au succès : invalide « mes fichiers » (`getListMyPreviewsQueryKey`), notifie « Fichier dupliqué », ferme la fenêtre et ouvre la copie (`paths.gpxToolsView`). Tests qui couvrent : `GpxPreviewView.test.tsx`, `DuplicateRouteModal.test.tsx` ; e2e `flow-gpx-tools.e2e.ts` (écrit, non lancé). **À ne pas défaire** : pas d'interface mobile (les outils GPX sont web uniquement, le client mobile est seulement régénéré) ; aucune mention de l'original sur la copie.
