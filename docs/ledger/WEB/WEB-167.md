## Livré

`WEB-167` **Cartes homogènes entre l'app et le site, côté site** (12 novembre 2026, contrat 14.6.0) — pendant de
`MOB-139` : mêmes quatorze règles (`KIT.md` §9). Le site gagne « Changer pour {groupe} », le lien « Quitter le groupe »,
le bouton « GPS » unique, la ligne météo de l'app, les avatars teintés par personne, « Rejoindre l'équipe » sur la carte
d'équipe, « Créer une sortie » sur un modèle, le menu ⋯ signaler / bloquer ; il perd « Publié », la visibilité par
défaut, les compteurs à zéro, la confirmation de désinscription, les badges Face / Dos sur les cartes. Nombres selon la
langue ; l'espace des milliers est rendue lisible par une mini-police limitée à U+202F tant qu'Inter n'est pas servie
(`WEB-170`). Galerie de développement `dev/cards.html` (absente du build), capturée par
`scripts/capture-card-gallery.mjs`. Tests : `components/card/*.test.tsx`, `utils/formatCases.test.ts`. **À ne pas
défaire** : `lib/avatarTint.ts` recopie la table de l'app ; `utils/visibilityException.ts` et `utils/cardState.ts`
portent seuls la règle des badges. Recette en navigateur : `WEB-172`. Écart voulu : `WEB-171`.
