## Livré

`WEB-169` **« Modifier une copie » d'un parcours, en aperçu GPX** (12 novembre 2026, contrat `14.1.0` par `API-180`) — pour qui est connecté mais ne peut pas modifier le parcours (non supprimé, avec un GPX) : un bouton à côté des téléchargements (`RouteDetailView.extraActions`, ajout dans la rangée existante, `data-testid="route-downloads"`) crée l'aperçu sans fenêtre (`useCreatePreviewFromRoute`), invalide « mes aperçus », notifie et ouvre son édition (`paths.gpxToolsEdit`). L'aperçu garde le titre du parcours. Tests qui couvrent : `RouteDetailView.test.tsx` (rangée avec ou sans `extraActions`, `extraActions={false}`) ; e2e `flow-routes.e2e.ts` (écrits). **À ne pas défaire** : rien n'est créé dans l'équipe ; pas de fenêtre, le nom est celui du parcours.
