## Livré

`WEB-182` **La carte d'une sortie ou d'un voyage ne plante plus sur un navigateur ancien** (15 novembre 2026, contrat inchangé) — remontée automatique [pedalons-feedback#16](https://github.com/glandais/pedalons-feedback/issues/16), `TypeError: toSorted is not a function` sur Chrome 103 (le dernier Chrome de macOS 10.12, donc sans mise à jour possible), à la première sortie ouverte après une inscription. `RoutesMapView.tsx` triait les traces avec `Array.prototype.toSorted` (Chrome 110, Safari 16, Firefox 115), arrivé le 5 novembre avec `WEB-130` ; c'était le seul appel du code web. Remplacé par une copie triée (`[...].sort`), au comportement identique. Couvert par `RoutesMapView.test.tsx` (« draws on a browser without Array.prototype.toSorted »). Non décidé ici : le plancher de navigateurs du site (ni cible de build ni polyfill dans `vite.config.ts`) — les dépendances peuvent encore échouer plus loin sur un navigateur de cet âge.
