## Livré

`WEB-178` **Mode « Météo » sur la carte d'une sortie à plusieurs parcours, pour le groupe où l'on est inscrit** (13 novembre 2026, contrat inchangé) — pendant de `MOB-152`. La carte multi-parcours de la page d'une sortie n'avait aucun interrupteur : le vent ne se voyait que sur la page d'un groupe. `RideOverviewMap` (le pendant de `TripOverviewMap`) pose sous la carte « Parcours | Météo » et la légende du vent quand la personne est inscrite dans un groupe dont le leg offre le vent (`rideMapWinds`, la règle `groupWindLeg` de la page du groupe) — ou sur une sortie solo à deux parcours, pour son groupe unique, comme dans l'app : le parcours de ce groupe se colore par son vent, avec ses pastilles, les autres gardent leur couleur ; choisir « Météo » sélectionne ce parcours, donc son profil. Tests : `RideOverviewMap.test.tsx`, `rideMapRoutes.test.ts` (`rideMapWinds`). À ne pas défaire : inscrit nulle part, pas d'interrupteur ; jamais le mode par défaut ; le mode est un état local, pas un `?color=` (celui-ci reste aux cartes d'un seul parcours).
