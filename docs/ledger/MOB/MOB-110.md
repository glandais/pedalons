## Livré

`MOB-110` **Publier la 1.2.0 sur l'App Store (XS)** — la 1.2.0 est en vente depuis le
17 novembre 2026 (`READY_FOR_SALE`, lu par `asc versions list`), avec la **build 107** (tag
`mobile.1.2.0.107`). La version App Store Connect 1.1.3, jamais soumise, était devenue la 1.2.0
(`MOB-147`, id `14f5c3e9-ceb2-42e5-9666-c5202da0134c`, `MANUAL`). Le 16 novembre 2026 : build 107
attachée à la place de la build 98 (une 1.1.3), nouveautés de `mobile/metadata/version/1.2.0/`
réécrites pour couvrir aussi l'écriture dans l'app (publications, annonces, voyages, éditeur
riche, tracé de parcours, gestion d'équipe) et poussées par `asc metadata apply` ; `asc validate`
n'a relevé ni erreur ni alerte ; déclarations de `MOB-159` faites et version soumise à la revue le
même jour. Aucun changement de contrat, rien à tester dans le dépôt.

Écart assumé le 16 novembre : la soumission a eu lieu avant le 28 novembre malgré les recherches
encore présentes dans le journal d'accès (`MOB-159`, point 3).

La version suivante, 1.2.1, a été créée dans App Store Connect le 17 novembre 2026 (id
`4e5c5e6b-6f6d-487f-bc1e-48599bd6a1b7`, `MANUAL`) ; sa fiche est dans
`mobile/metadata/version/1.2.1/`.
