## Livré

`API-198` **Générateur de parcours sur le réseau de l'équipe** (14 au 16 novembre 2026, contrats `14.14.0` à `14.15.0`, puis remplacé en `15.0.0`) — preuve de concept livrée en trois lots : appariement des traces à des arêtes (`gpx_tracks.network_edges`, `V91`, `NetworkEdgesBackfill`), recherche Java sur le réseau de l'équipe, endpoint `POST /api/teams/{teamSlug}/route-generator`, garde-fous (`ROUTE_GENERATOR_RATE_LIMITED`, `ROUTE_GENERATOR_BUSY`), `Route.excludedFromGenerator` (`V93`). Sa recherche est retirée le 16 novembre 2026 : le moteur d'osm-route-details a atteint la parité sur le banc (`API-206`). Le détail des mesures est dans les notes archivées ([`plans/archive/2026-11-13-generateur-boucles-equipe.md`](../../plans/archive/2026-11-13-generateur-boucles-equipe.md) et ses lots). Ce qui en reste est couvert par `NetworkEdgesBackfillTest`, `NetworkEdgesDocumentTest`, `ElevationRefreshEdgesOnlyTest`, `RouteExcludedFromGeneratorResourceTest` et `RouteGeneratorGuardTest` (fenêtre de 30 demandes par 15 minutes) ; les tests de la recherche, de l'oracle et du cache sont partis avec elle. Ce qui restait à régler sur la recherche Java est écarté sous `API-205`. **À ne pas défaire** : `network_edges` et son rattrapage, l'exclusion par parcours (une copie garde la case), 403 pour une personne non membre (règle de `PlannerAccess`), les parcours masqués par la modération nourrissent le réseau.
