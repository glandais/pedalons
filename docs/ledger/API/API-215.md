## Livré

`API-215` **Générateur : consigne de part de chemins en gravel et VTT, contrat 16.3.0** — le 23 novembre 2026, contrat
`16.3.0` (ajouts seulement), lot 5 du générateur (ledger `API-207`, plan §12 octies). `RouteGeneratorRequest` prend
`unpaved` (`RouteGeneratorUnpaved` : `LOW`, `USUAL`, `HIGH`) ; `GeneratedRouteDto` rend `unpavedTarget` et
`unpavedTargetReached`.

- **Traduction** (`RouteGeneratorService`) : `LOW` 0,25, `USUAL` 0,47, `HIGH` 0,60 de la longueur hors revêtement,
  envoyés au moteur en `offroad_target` (osm-route-details `1.15.0`, API 1.14). Sans réglage, une demande gravel ou VTT
  vaut `USUAL` ; une demande route n'envoie rien, quel que soit le réglage.
- **Garde de version** : la consigne part seulement si `generator.offroad.ride_types` des capacités annonce le type.
  Un moteur revenu en arrière pendant l'heure de cache des capacités refuse la clé (400) : la demande est refaite une
  fois sans elle, au lieu d'un 503 pour chaque génération gravel. Un 400 d'un moteur qui annonce toujours le type n'est
  pas refait.
- **Part rendue** : `unpavedShare` se lit sur `offroad_share` (la définition de `/v1/route-details` : tag `surface`,
  puis `tracktype`, puis classe), et sur `unpaved_share` (le tag seul) d'un moteur plus ancien. `unpavedTargetReached`
  se juge par parcours, à la tolérance que rend le moteur.
- **Tests** : `RouteGeneratorResourceTest` (`aGravelRideWithoutALevelAsksForTheUsualShare`,
  `theThreeLevelsAreTranslatedToTheirShare`, `aRoadRideSendsNoTargetWhateverTheLevel`,
  `nothingIsSentToAnEngineThatDoesNotAnnounceTheRideType`, `anEngineRolledBackWithinTheHourIsAskedAgainWithoutTheTarget`,
  `aRefusedTargetTheEngineStillAnnouncesIsNotRetried`, …), `RouteGeneratorGatewayHttpTest`, `GeneratedRouteSanityTest`.
- **À ne pas défaire** : les crans sont calés sur la définition du graphe du moteur, pas sur la typologie des tuiles de
  la page d'un parcours, plus basse d'environ 8 points (ledger `API-214`). L'app l'envoie depuis `MOB-154`,
  avec les mêmes crans ; sans réglage, `USUAL`, qui n'est pas écrit.
- **En production le 23 novembre 2026** (build `5e000c6`, staging puis prod), après osm-route-details `1.15.0` (`OPS-67`).
