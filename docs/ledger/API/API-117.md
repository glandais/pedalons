## Livré

`API-117` **Drapeau de la mesure d'audience dans `/api/config`** (2026-10-15, **API 11.3.0**,
pas de migration) — plan [`2026-10-15-web-analytics.md`](../../plans/2026-10-15-web-analytics.md)
(§3.3, étape 2 du §8). Le site n'avait aucun moyen de savoir si le déploiement compte les
visites : le conteneur frontend ne reçoit que `API_BASE_URL`. `ConfigDto` gagne `analytics`
nullable (`AnalyticsConfigDto { countPath }`), alimenté par `pedalons.analytics.count-path`
(`PEDALONS_ANALYTICS_COUNT_PATH`) en `Optional<String>` dans `ConfigService`, sur le modèle de
`webPush` : vide ou absent, `analytics` est null et le site n'envoie rien ; `%dev` et `%test`
le forcent à vide même si la variable fuit. Le chemin est vérifié par liste blanche
(`ConfigService.SAME_ORIGIN_PATH`, `/[A-Za-z0-9._~-][A-Za-z0-9._~/-]*`) : une URL complète,
`//hôte`, `/\hôte`, `/<TAB>/hôte` (qu'un navigateur lit comme `//hôte`), une query string
ou `/` seul laissent le drapeau à null. Clients web et mobile régénérés (`contract-first-api`),
le mobile ignore le champ. Tests : `ConfigServiceTest` (`getConfig_withoutCountPath_offersNoAnalytics`,
`analytics_isNullWhenAbsentOrBlank`, `analytics_carriesTheTrimmedSameOriginPath`,
`analytics_refusesAPathThatWouldLeaveTheOrigin`) — verts au 16 octobre 2026. **À ne pas défaire** : seul un chemin de la
même origine est servi, vérifié par liste blanche et non par une liste d'échappements ; une
valeur d'une autre forme coupe le compteur au lieu de compter ailleurs ; aucun drapeau par
`Domain` (`API-116`) ; le drapeau ne se pose qu'en prod, après la politique (`OPS-41`).
