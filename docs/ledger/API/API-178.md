## Livré

`API-178` **Distance et dénivelé d'affichage d'une sortie, calculés par l'API** (12 novembre 2026, contrat 14.6.0) —
`RideDto` et `CalendarEventDto` portent `displayDistance` et `displayElevationGain` pour la personne qui lit : le
parcours de son groupe si elle est inscrite, sinon le parcours que tous les groupes partagent (un groupe sans parcours
roule celui de la sortie), sinon rien ; un parcours supprimé compte pour aucun. Calcul dans
`service/ride/RideDisplayFigures`, résolu par page (aucune requête de plus par ligne ; une requête de plus par fenêtre
de calendrier). Champs ajoutés seulement : `distance` et `elevationGain` restent. Tests : `RideDisplayFiguresTest`,
`RideDisplayFiguresResourceTest`, `CalendarQueryCountTest`, `ParticipationQueryCountTest` ; suite complète verte sur
optiplex (4 758 tests). Lu par les cartes des deux clients (`MOB-139`, `WEB-167`).
