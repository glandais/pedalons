## Livré

`API-147` **Le compte des relecteurs des stores ne peut plus être supprimé** (31 octobre 2026, contrat d'API inchangé) — un relecteur des stores avait supprimé `marketplace-tester@pedalons.fr` : le compte était effacé, et le relecteur suivant n'avait plus rien pour se connecter. `UserService.deleteUser` ne supprime plus les adresses de `pedalons.account-deletion.protected-emails` (par défaut ce seul compte ; `PEDALONS_ACCOUNT_DELETION_PROTECTED_EMAILS` dans le `.env` remplace la liste). Pour ces comptes, il révoque les sessions et répond 204 comme pour une vraie suppression, sans rien effacer : le relecteur voit le parcours aller jusqu'au bout, puis se reconnecte avec les mêmes identifiants. Couvert par `UserResourceTest.deleteCurrentUser_protectedAccount_signsOutButErasesNothing`. À ne pas défaire : **pas d'erreur visible**, car App Review vérifie que la suppression de compte fonctionne (règle 5.1.1(v)), et un refus exposerait le compte de démo à un rejet.
