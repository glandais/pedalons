## Livré

`API-222` **Un onglet « Statistiques » dans l'administration de la plateforme, en décomptes** — API
`16.8.0` : `GET /api/admin/domains/platform-stats?domainId=` (`@Admin`, 404 si le domaine est
inconnu ou supprimé) rend comptes, méthodes d'authentification, clés d'accès, inscriptions sur
douze mois, équipes, services GPS, appareils push, clients des 30 derniers jours et flux de
calendrier (`PlatformStatsRepository`, une requête par bloc). Aucune ligne ne nomme ni n'identifie
une personne. Page web `AdminStatsPage.tsx` ; l'app n'a rien. Couvert par
`AdminPlatformStatsResourceTest` (403, 404, décomptes, filtre de domaine, absence de nom et
d'e-mail). `clientsLast30Days` classe d'abord par `device_client` (OAuth, appareil appairé), puis
par agent utilisateur.
