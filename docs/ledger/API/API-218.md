## Livré

`API-218` **Les sélecteurs de parcours n'offrent plus les parcours supprimés** (2026-11-25, contrat `16.7.0`) — la liste des parcours d'une équipe (`GET /teams/{slug}/routes`) montre à un administrateur les parcours supprimés, et le sélecteur de parcours de l'éditeur de sortie et de voyage la réutilisait tel quel, sur le site (`RoutePickerModal`) comme dans l'app (`RideEditorRepository.searchRoutes`) : un administrateur se voyait proposer des parcours supprimés. La liste accepte désormais `excludeDeleted` (booléen, faux par défaut, `RouteListParams`), que les deux sélecteurs passent à vrai. Test : `RouteResourceTest.listRoutes_excludeDeleted_hidesDeletedRoutesFromAnAdmin`. **À ne pas défaire** : la liste des parcours de l'équipe garde les supprimés pour un administrateur (c'est d'elle qu'il les restaure) ; le filtre est un paramètre demandé par le sélecteur, pas un changement de la règle `isIncludeDeleted`. Le compte (`/routes/count`) ne prend pas ce paramètre : aucun sélecteur ne l'appelle. `getRoutesBulk` (les parcours déjà posés sur la sortie) est inchangé.
