## Livré

`API-102` **La pluie se lit en pouces pour un lecteur en impérial** (12 novembre 2026, commit `088876724`, avec `MOB-139` et `WEB-167` ; contrat d'API inchangé, l'API parle toujours en millimètres) — un lecteur en `IMPERIAL` lisait « 54 °F · 12 mph · 2.3 mm ». Les deux clients convertissent ensemble : `formatPrecipitation` côté web (`frontend/src/utils/unitFormat.ts`), `UnitSystem.precipitation` / `precipitationSymbol` et `AppFormatters.formatPrecipitation` côté mobile (`core/units/unit_system.dart`, `core/utils/formatters.dart`). La clé `rides.weather.precipitationWithAmount` ne porte plus l'unité. **À ne pas défaire** : le centième de pouce (un dixième vaut 2,5 mm, trop grossier pour une averse), le dixième de millimètre en métrique. Le préréglage britannique reste ouvert (`API-103`).
