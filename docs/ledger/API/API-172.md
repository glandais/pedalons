`API-172` **Arrivée et durée estimées par groupe et par étape** (2026-11-10, **contrat `13.5.0`**, mineure, ajout pur ; aucune migration) — pour `MOB-134`. Tests qui couvrent : `PublicationEndCalculatorTest` (`estimate_…`, cinq cas), `RideResourceTest.getRide_groupsCarryTheirEstimatedArrival_onlyWithADistanceAndASpeed`. **À ne pas défaire** : **absents** sans distance ou sans vitesse — l'écran n'affiche rien plutôt qu'une estimation ; les 3 h par défaut ne valent que pour la fin stockée (`legEnd`), jamais pour ces champs.
Tests backend des quatre entrées : écrits au lot 1, une première passe a donné les corrections du commit `efef47b12` (planificateur, politique de rafraîchissement, `RideSwitchAnswer`, type de contenu des tests `switch`), puis la suite complète est passée sur optiplex (4 584 tests, 0 échec) — **avant** le rebase sur develop et la fusion de `RideGroupDto` : à relancer en entier avant la fusion.
