## Livré

`API-155` **Plus d'entité ni de dépôt pour les deux files mortes du revêtement** (phase F,
étape 1, 2026-11-07, sans changement de contrat ni migration) (scindé d'`API-151`) — chaque
écriture de revêtement retirait encore la ligne `surface_refresh` de sa cible, pour qu'une version
antérieure à la phase E ne la réclame pas plus tard ; plus aucun environnement ne fait tourner une
telle version, et osm-surface est parti (`OPS-59`). Retirés : `SurfaceRefreshRepository` et ses
six appels (`RouteService`, `GpxPreviewService`, quatre dans `ElevationRefreshService`), les
entités `SurfaceRefresh` et `RawTrackResurface`, leurs lignes d'`import-test.sql` et l'aide de
test `LegacySurfaceRequests`. Les tests qui posaient une ligne « laissée par une version
précédente » sont retirés ; ceux qui vérifiaient qu'une trace sans document, son rattrapage HD
fini, ne dit rien gardent ce cas sans la ligne
(`SurfaceRefreshTest.aTrackWithoutADocument_afterItsHdCatchUp_readsAsNothing`,
`GpxPreviewSurfaceRefreshTest.aPreviewWithoutADocument_afterItsHdCatchUp_readsAsNothing`). À ne
pas défaire : **les deux tables restent en base**, inertes (la validation du schéma ignore une
table sans entité, leurs clés étrangères cascadent en base) ; leur suppression est la migration
`V85`, seule dans la version suivante (`API-156`).
