## Reste à faire

`API-214` **Typologie des tuiles de route-details : 12,6 % des tronçons gravel sans classe de revêtement** — le relevé
5a du lot 5 du générateur (osm-route-details, `docs/design/technique/ord-loops-lot5-mesures.md`, §3) montre que les
`network_edges` des boucles gravel enregistrées n'ont aucune classe de revêtement (`sc`) sur 12,6 % de leur longueur : la
typologie que route-details tire des tuiles ne rend rien sur ces tronçons, qui s'affichent « inconnu ».

- **Dégradation** : la page d'un parcours enregistré montre environ 8 points de non-revêtu de moins que la carte du
  générateur, qui lit le graphe préparé depuis le PBF (15 points au P90). Les crans « Peu », « Comme d'habitude »,
  « Beaucoup » (lot 5, ledger `API-207`) sont calés sur la définition du graphe.
- **Où** : la classification de surface d'osm-route-details (`crates/ord-core/src/classification/`, adaptateur de tuiles
  `crates/ord-adapters/src/streets/`), et le rattrapage des `network_edges` côté Pédalons une fois corrigée.
- **Décidé le 23 novembre 2026** : le lot 5 continue avec cette limite notée ; la correction est un chantier à part.
  À faire : trouver pourquoi la typologie est vide (attributs absents des tuiles, appariement), corriger, puis recalculer
  les `network_edges` et mesurer l'écart de nouveau.
