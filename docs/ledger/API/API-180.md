## Livré

`API-180` **Aperçu GPX créé depuis un parcours** (2026-11-12, **contrat `14.1.0`**, mineure, ajout pur ; aucune migration) — `POST /api/teams/{teamSlug}/routes/{routeSlug}/preview` → `201 GpxPreviewDto`, pour tout compte connecté qui peut lire le parcours (`@RolesAllowed("user")`, `@Logged`, `@CheckAccess(ROUTE, READ)` : un parcours `TEAM` lu hors de l'équipe répond 404, un anonyme 401). `GpxPreviewService.createFromRoute` crée l'aperçu sous **le nom du parcours** (pas celui du fichier), avec ses points du parcours (`WaypointPlan(drafts, false)`, départ `KEEP`) et, si le planificateur GPX du domaine est activé, son état du planificateur (`drawn` suit l'état) : l'aperçu appartient à l'appelant, qui seul peut le modifier et lire ce planificateur. Rien n'est créé dans l'équipe ; une source supprimée répond 404. Tests qui couvrent : `RoutePreviewFromRouteResourceTest`. **À ne pas défaire** : cet appel donne l'état du planificateur d'un parcours à qui peut seulement le lire — exception assumée à « planificateur = UPDATE » (`RouteService.getPlannerState`), décidée le 12 novembre 2026 ; un organisateur peut ensuite l'« Enregistrer comme parcours ».
