# Logos

L'icône de Pédalons : un « P » en cadre de vélo, orange `brand-orange` (#fd7e14) sur un carré arrondi bleu `brand-blue` (#228be6), rayon 96 px sur 512.

- `icon.svg` — la source nettoyée (copie de `assets/icon.svg`), d'où tout le reste est généré par `scripts/generate-icons.sh`.
- `icon-1024.png` — l'intermédiaire rastérisé, pour les grands formats.
- `maskable-icon-512x512.png` — la version PWA *maskable*, avec sa zone de sécurité.

Règles : ne jamais redessiner ni recolorer le logo ; pas d'indigo dedans, pas de bleu de logo dans l'interface. Dans un en-tête, le nom s'écrit en texte (« Pédalons », 20 px, 700, `primary`), pas en logotype.
