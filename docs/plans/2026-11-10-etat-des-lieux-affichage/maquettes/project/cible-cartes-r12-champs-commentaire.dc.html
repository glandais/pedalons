Inchangé
Ce qui change
  • App : le commentaire s’affiche tel qu’il a été tapé, comme sur le site ; seuls les retours à la ligne comptent.
  • Raison : aucune des deux saisies ne propose le Markdown (TextField nu, Textarea nu) ; rendu, il change ce qu’on a écrit et un lien [texte](adresse) y cache son adresse.
  • Site : inchangé.
Variante (option 2) — Markdown rendu des deux côtés, annoncé sous le champ
Le site rend le Markdown comme l’app ; les deux champs disent ce qu’ils acceptent.
